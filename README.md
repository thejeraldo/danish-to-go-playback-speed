# Danish To Go - Playback Speed

A simple Chrome extension that adds playback-speed controls to audio players on Danish To Go.

## Features

- 0.5× playback speed
- 0.75× playback speed
- 1× playback speed
- 1.25× playback speed
- 1.5× playback speed
- 2× playback speed
- Remembers your selected playback speed

## Installation

1. Download this repository from GitHub.
2. Extract the ZIP file.
3. Open Chrome and go to `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the folder containing `manifest.json`.
